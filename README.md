# Anvil

**Portable GrapheneOS-derived security hardening for every Android device that can
physically take it — with an honest, evidence-backed per-device security matrix.**

Status: under active construction. Live progress: [`progress/index.html`](progress/index.html).
Plan and honesty policy: [`docs/plan.md`](docs/plan.md).

Anvil measures itself against the [GrapheneOS](https://GitHub.com/GrapheneOS) org's
actual public repositories, artifact-for-artifact, and documents hardware limits as
rigorously as it documents capabilities. See the plan for the comparison table and
the honesty policy before trusting anything here — that is the point of it.
